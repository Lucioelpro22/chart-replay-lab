# Chart Replay Lab

Entrenador profesional y gratuito para practicar lectura de mercado vela por vela sin riesgo.

## Funciones

- Replay de 100 velas sintéticas con reproducción, avance manual y velocidades.
- Decisiones LONG, SHORT o ESPERAR con nivel de confianza y tesis.
- Evaluación automática tres velas después.
- Score de proceso, disciplina, calibración y consistencia.
- Plan previo de sesión con objetivo, sesgo y riesgo máximo.
- Planificador de stop, target y relación riesgo/beneficio.
- Exportación del diario a CSV y métrica de precisión.
- Atajos de teclado para un flujo de práctica más rápido.
- Diario persistente en `localStorage`, tema claro/oscuro y diseño responsive.

## Ejecutar localmente

No requiere build ni dependencias. Abrí `dist/index.html` o serví la carpeta:

```bash
npx serve dist
```
